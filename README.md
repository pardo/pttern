# pttern

Design seamless embossed tile patterns and export 3D-printable mold kits.

**Try it:** https://pardo.github.io/pttern/

## Development

```sh
npm install
npm run dev      # local dev server, also reachable from a phone on the same network
npm run build    # production build in dist/
```

Every push to `main` builds the app and deploys it to GitHub Pages.
